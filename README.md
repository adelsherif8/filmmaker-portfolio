# Filmmaker Portfolio — Omar Emad El Din

An animated personal portfolio / online CV for filmmaker **Omar Emad El Din**,
featuring smooth scroll, motion animations, showreel videos, and a downloadable CV.

## Tech Stack

- **React + Vite**
- **Framer Motion** — animations
- **Lenis** — smooth scrolling

## Project Layout

```
portfolio/
  ├─ src/         React components
  ├─ images/  videos/   media assets
  ├─ cv/        downloadable CV
  └─ public/
```

## Getting Started

```bash
cd portfolio
npm install
npm run dev
npm run build
```
